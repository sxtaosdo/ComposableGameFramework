# Hybrid Reference（混合产品参考装配）

## 1. 示例

目标产品：

> 东方仙侠 + 暗黑 Build + 生活模拟家园

## 2. 组合

```text
ARPG Feature Pack
+
LifeSim Feature Pack
+
Social Feature Pack
```

## 3. Ruleset

```text
Diablo-like Combat
Chinese Fantasy Progression
LifeSim Relationship
LifeSim Farming
Custom Sect Rules（宗门规则）
```

## 4. 核心循环

```text
家园 / 种田 / 炼丹
↓
探索秘境
↓
暗黑式战斗
↓
掉落材料与装备
↓
建设洞府
↓
NPC / 宗门关系成长
```

## 5. 关键价值

该产品用于验证：

> 不同 Feature Pack 能否组合，而不产生 Core 冲突和跨模块硬耦合。
