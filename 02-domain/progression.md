# Progression（成长）

## 1. 原则

成长不是单一 Level（等级）系统。

允许多个 Growth Track（成长轨道）并存。

## 2. Growth Track 示例

```text
Character Level
Skill Level
Profession
Mastery
Talent
Reputation
Relationship Level
Season Rank
```

## 3. 统一能力

每个成长轨道可以定义：

```text
Progress Value
Threshold
Level
Reward
Unlock
Modifier
Reset Policy
```

## 4. Ruleset 决定

例如传奇：

```text
角色等级
技能等级
装备强化
```

暗黑：

```text
角色等级
技能树
巅峰
装备 Build
```

生活模拟：

```text
Farming
Fishing
Mining
Foraging
Relationship
```

## 5. Reward（奖励）

成长奖励通过：

```text
Effect
Command
Unlock Capability
Modifier
```

实现，不直接侵入其他 Feature。

## 6. Reset（重置）

支持可选：

```text
转生
赛季重置
洗点
职业切换
```

但由具体 Ruleset 决定。
